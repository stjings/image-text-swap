# 기준 샘플 이미지

기획서(PLAN.md) 4장에서 정의한 검증 기준 이미지를 둔다.
마일스톤 완료 판정은 모두 이 두 파일로 한다.

| 파일 | 역할 | 특징 |
|------|------|------|
| `sample-simple.png` | 샘플 A — M0 스파이크 대상 | 단색 글자 2줄, 배경 단순 |
| `sample-complex.png` | 샘플 B — M4 이후 실전 검증 | 텍스트 블록 약 20개, 배경 구간별 상이 |

## 올릴 때 주의

**반드시 원본 파일을 넣는다.** 캡처본이나 메신저를 거친 파일은 JPG로 재압축되며
알파 채널이 사라진다. 그러면 배경 유형 판정(PLAN.md 7-1)이 실제와 다른 조건에서
검증되어 M0 결과를 신뢰할 수 없다.

원본이 처음부터 JPG인 것은 괜찮다 (PLAN.md 13장에 해당 케이스 반영됨).
문제가 되는 것은 "원래 PNG였는데 전달 과정에서 JPG가 된 것"이다.
